#FILE: CLONAR_CLONA_TIPOS_SIEMPRE.txt
Asunto: [Bug] La clonación de variables con $ copia el tipo original ignorando el tipado explícito

Descripción:
Al usar `$variable` para asignar a una variable con tipado explícito, 
el tipo de la variable original prevalece sobre el tipo declarado.

Ejemplo:
  str_num = "100"          # string
  int num_convertido = $str_num   # Se espera int
  
  printAllVars() muestra:
    num_convertido: "100" (string)  # ¡Sigue siendo string!

Comportamiento esperado:
  - Si se declara `int variable = $str_num`, debería convertirse a int.
  - O al menos debería lanzar un error de tipo.

Comportamiento actual:
  - El tipo original se clona, ignorando el tipado explícito.
  - Esto puede causar errores difíciles de depurar.

Sugerencia:
  - Opción 1: Hacer que `$` convierta al tipo declarado.
  - Opción 2: Crear funciones `tonumber()`, `tostring()` para conversión explícita.
  - Opción 3: Lanzar advertencia/error si los tipos no coinciden.
