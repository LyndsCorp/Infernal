Hay que añadir estos operadores:
+= --> sirve para sumar como en C
-= --> sirve para restar como en C
*= --> sirve para multiplicar como en C
/= --> sirve para dividir como en C
** --> sirve para hacer potencias como en Python (no tiene su version como **=)
x++ --> suma 1 como en C
x-- --> resta 1 como en C
(Nota: no añadamos ++x ni --x)
() --> prioridad, jerarquia de operaciones. Calcula lo que está entre parentesis antes que lo demás.

Siguiendo la convención de las matemáticas, si pones:
2 + 3 ** 2
Se traduce a:
2 + (3 ** 2)
