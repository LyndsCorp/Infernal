#FILE: EXPANDIR_COMANDOS_CON_LISTAS.txt
Se deberían de poder expandir comandos de shell con listas para así hacer librerías más fácil. Por ejemplo:
``` Infernal
function copiarArchivo(list archivos)
    cp $archivos
fi

copiarArchivo(["-r", "/home/david/linux-7.1-src/", "/boot"])
```
y eso le pasaría al shell este comando:
``` Shell
cp -r /home/david/linux-7.1-src/ /boot 
```
> Nota: dará error de permiso de escritura, pero hagamos como que funciona.
