#FILE: FUNCIONES_BONITAS.txt
Esta sería una pequeña mejora pero que puede ahorrar un poco de tiempo a la hora de escribir.
Por ejemplo, ahora mismo se puede:
``` Infernal
text = "hola"
if head(text, "h") then
   #se cumple
fi
```
Pero también que se permita:
``` Infernal
text = "hola"
if text:head("h") then
   #se cumple
fi
```

Lo que esto haría es que el primer argumento de la función obtiene el valor de la variable especificada.
Si la función esperaba un int pero se le dió un string, que dé error de tipado fijo.

Y que no solo sirva para eso, sino que también guarde cómo se creó esa variable así:
``` Infernal
import lib
var = lib.func()
```
Y ahora podrías hacer lib:algo() y ese algo() puede estar tanto en el ámbito de funciones accesibles por el script como por las funciones del Fire llamado `lib`.


También que se puedan crear funciones globales con:
``` Infernal
global function algo()
    #algo
fi
```
