Añadir un switch como en C que se use así:
``` Infernal
switch VARIABLE
    case valor
        break
    case algo #ejecuta el mismo código que el case otro. tiene el fi aquí pero puede estar en otra línea, solo si está vacío se permite
    case otro
        break
    default
        mkdir hola #esto es un comando de shell
        break #el si no se pone aquí un break, error de sintaxis
fi # cerrar el switch
```
