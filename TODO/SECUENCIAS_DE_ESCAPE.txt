#FILE: SECUENCIAS_DE_ESCAPE.txt
A Infernal le faltan secuencias se escape para prints y todo eso, entonces propongo:
\n -> salto de linea
\t -> tabulador
\\ -> barra invertida (\)
\" -> comillas dobles
\' -> comilla signilar
\r -> retorno de carro
\N -> (ESPECIAL) quitar el último salto de línea (incluyendo el que viene con print() o con echo)
\033... -> secuencias de escape ANSI
