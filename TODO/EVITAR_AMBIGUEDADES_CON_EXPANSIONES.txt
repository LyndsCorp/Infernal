También que se pueda usar ? y que se reemplace como $ en las expansiones, ya que el $ es para las expansiones de Infernal y para las expansiones de shell hace falta $ también.
Me explico:
``` Infernal
echo ?HOME
```
Esto se expande como:
``` Shell
echo $HOME
```
y devuelve el valor de HOME en el shell.

También que se pueda en la definición de variables:
```
home = echo ?HOME
print(home) #Imprime: /home/david
```
