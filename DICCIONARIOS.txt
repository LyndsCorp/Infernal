#FILE: DICCIONARIOS.txt
Mientras hacía Lynter, me dí cuenta de algo: los tipos de variables en Infernal están incompletos. Solo hay:
bool
int
string
float
list
Pero faltan los diccionarios que el vartype podría ser:
map
Mejor que dict, corto y bonito.
Entonces, los mapas/diccionarios son como listas pero en vez de guardar valores por índice, los guardan por una palabra clave.
Ejemplo de un map:
``` Infernal
stats = [
    "username" = "Hola",
    "vida" = 800,
    "fuerza" = 600
]
```
o
``` Infernal
stats = ["username" = "Hola", "vida" = 800, "fuerza" = 600]
```
Entonces se pueden llamar con:
golpe = $stats["vida"] - stats["fuerza"]
O algo asi. O sin el $ en algún futuro, pero de momento con el $ para evitar ambugüedades con los comandos de shell.
